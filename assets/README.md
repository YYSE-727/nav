# assets · 图片都放这里

网站首页的**轮播大图**和卡片右上角的**小缩略图**，都从这个文件夹读图。

## 怎么用

1. 把图片复制进这个文件夹。文件名用英文 / 数字 / 连字符，例如 `qidian.jpg`、`esj-zone.png`。
2. 打开 `data/sites.json`，找到对应站点那条记录，在 `"category"` 那一行下面加一行：

   ```json
   "image": "assets/qidian.jpg",
   ```

   注意三点：路径要以 `assets/` 开头；行尾逗号别漏；引号必须是英文的 `"`。
3. 双击 `更新.cmd` → 双击 `发布.cmd`。

## 更省事的办法

双击项目根目录的 `加网站.cmd`，向导会问你「图片文件名」，并自动把上面那一行写好。

## 三条规则

- **没写 `image` 的站点**：轮播自动生成「首字母大字」设计卡片，卡片右边显示首字母方块。这不会报错，属于正常样式。
- **写了 `image` 但图片还没放进来的**：自动退回首字母样式，`更新.cmd` 会打印一条提醒告诉你哪个文件缺了。所以可以先写文件名、后放图，不会出现半张破图。
- **图片规格建议**：轮播区域是一块横幅（桌面高 312px、手机 260px），建议用**横向 16:9 或更宽**的图，宽度 1600px 左右足够；单张压到 300KB 以内，否则会明显拖慢网站打开速度。

## 关于版权

轮播展示的图片会随网站一起公开。放动漫截图、官方宣传图这类素材时，请自行确认使用范围；不确定来源的图，宁可先用自动生成的首字母卡片。
