一句话简介

风格统一的可改色扁平插画库，直接下载 SVG / PNG，适合落地页与产品空状态配图。

详细介绍

unDraw 是一个开源扁平插画资源库，插画风格统一，支持在线切换主色调后下载 SVG 或 PNG，适合用于落地页、产品空状态、演示文稿等场景。公开资料普遍将其列为可免费商用（需遵守其开源许可）的插画来源，是设计资源清单中的常客。使用前建议按其许可证要求处理署名与传播方式。

适用场景

  • 给产品落地页配统一风格的插画
  • 做演示稿 / 海报时找扁平插画元素
  • 为界面空状态、错误页设计配图

核心功能

  • 插画风格统一，成套使用观感一致
  • 支持在线改主色，匹配品牌色
  • 提供 SVG 与 PNG 下载
  • 开源免费，可商用（以许可证为准）
  • 数量较大、题材覆盖面广

✓ 有依据的优点

  • 风格统一，成套使用不会显得杂
  • 可改色，贴合品牌视觉
  • 矢量格式便于二次编辑

✕ 有依据的缺点

  • 风格较单一，容易撞款
  • 部分素材需付费版本
  • 中文场景题材覆盖不如通用题材

使用限制

  • 插画风格偏单一（扁平线性），不适合所有品牌调性
  • 完整功能 / 高级素材需其付费服务（undraw plus）
  • 许可证要求需在商用前自行确认

推荐理由

当你需要在短时间内给页面配上一套风格统一的插画、又不想付费买图库时，unDraw 的改色 + 矢量特性最实用。
