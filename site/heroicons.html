一句话简介

由 Tailwind CSS 团队手工设计的免费 SVG 图标集，含 Outline / Solid / Mini / Micro 四种规格。

详细介绍

Heroicons 是由 Tailwind CSS 作者团队制作的手工 SVG 图标库，提供 Outline、Solid、Mini、Micro 四种规格，覆盖箭头、文档、用户、图表、设备等大量常见 UI 语义。图标可直接复制 SVG 使用，适合搭配 Tailwind 项目或任意前端框架，也适合设计师在 Figma 等工具中使用。

适用场景

  • 给后台系统 / 工具型产品快速配一套 UI 图标
  • 在 Tailwind 项目中使用官方推荐图标集
  • 做界面原型时补齐常用语义图标

核心功能

  • 四种规格（Outline / Solid / Mini / Micro）
  • 图标数量多、命名规范统一
  • 可直接复制 SVG 代码
  • 与 Tailwind CSS 生态深度契合
  • 免费使用

✓ 有依据的优点

  • 命名与尺寸规格统一，接入成本低
  • 由 Tailwind 团队维护，质量稳定
  • 免费、无使用门槛

✕ 有依据的缺点

  • 风格相对朴素，不适合做视觉亮点
  • 图标数量不及超大型图标库
  • 不支持在线改色导出（需自行处理 SVG）

使用限制

  • 只提供线性 / 实心基础图标，缺少插画与复杂品牌图标
  • 风格偏功能型，装饰性弱
  • 品牌 Logo 类图标需另找来源（如 Simple Icons）

推荐理由

当你在做一个界面产品、需要一套风格统一且接入方便的 SVG 图标时，Heroicons 的规格设计与复制即用体验很省事。
