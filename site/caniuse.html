一句话简介

查询 HTML5 / CSS3 / JS 特性在各浏览器版本支持情况的权威兼容性数据表。

详细介绍

Can I use 是前端开发常用的浏览器兼容性查询工具，官方定位为『HTML5、CSS3 等特性的支持表』。用户输入某个 CSS 属性、JS API 或 HTML 特性，即可看到各浏览器及版本的支持情况、全局支持率与已知问题说明。它是判断某个新特性能否投入生产环境的重要参考，页面也整合了 BrowserStack 等真实设备测试入口。

适用场景

  • 确认某个 CSS 新特性是否可安全使用
  • 评估某个 Web API 在目标浏览器上的支持情况
  • 为技术选型提供兼容性依据

核心功能

  • 覆盖 HTML5 / CSS3 / JS 等大量特性
  • 按浏览器与版本展示支持状态
  • 提供全局支持率统计
  • 标注已知问题与备注
  • 免费使用，无需注册

✓ 有依据的优点

  • 兼容性数据事实上的行业参考标准
  • 查询快、结论直观
  • 免费、无广告干扰（含少量合作入口）

✕ 有依据的缺点

  • 需要自行理解数据再作决策
  • 不涉及具体实现方案
  • 国产 / 小众浏览器覆盖不足

使用限制

  • 只提供数据与备注，不提供代码示例
  • 数据依赖社区与厂商更新，个别条目可能滞后
  • 部分细分场景（老旧国产浏览器）覆盖有限

推荐理由

当你要用一个较新的 CSS 或 JS 特性、需要先确认浏览器支持面时，Can I use 是最快的判断依据。

需求 — 匹配关系
