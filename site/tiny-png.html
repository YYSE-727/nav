一句话简介

把图片拖进网页就自动智能压缩 PNG / JPG / WebP，体积可减少约八成而肉眼几乎看不出差别。

详细介绍

TinyPNG（现由 Tinify 运营）是一款在线图片压缩服务，支持 PNG、JPG/JPEG 与 WebP。打开网页把图片拖入，服务端会自动压缩并显示压缩前后体积与节省比例，支持批量上传和打包下载。其压缩为有损算法，官方宣称可在不明显损失画质的前提下大幅减小体积。除免费网页版外，还提供 API、WordPress 插件、图片 CDN 等面向站长与开发者的商业化能力。

适用场景

  • 把手机照片压到社交平台可上传的大小
  • 给博客 / 网页配图瘦身以提升加载速度
  • 压缩 PNG 图标、截图后再用于 PPT 或网页

核心功能

  • 拖拽上传即压缩，无需注册即可使用
  • 支持 PNG / JPEG / WebP
  • 批量上传与一键打包下载
  • 显示压缩前后体积与节省百分比
  • 提供 API、WordPress 插件、CDN（付费 / 配额制）

✓ 有依据的优点

  • 压缩率高，公开资料普遍反映 PNG 常能压掉 60%–70%
  • 操作极简，基本没有学习成本
  • 支持批量并打包下载，适合处理成批配图

✕ 有依据的缺点

  • 免费额度有限，大批量需付费
  • 图片需上传服务器，存在隐私顾虑
  • 官网现以 Tinify 商业服务为主，免费网页入口的宣传被弱化

使用限制

  • 免费版对单次批量张数与单张文件大小有限制，额度按次计算
  • 图片需要上传到官方服务器处理，私密图片不建议使用
  • API 与大批量处理属于付费能力

推荐理由

当你需要省心地批量压小非私密图片、又不想装软件或调参数时，TinyPNG 最合适；若图片涉及隐私，请改用本地处理的 Squoosh 或 Picdiet。
