详细介绍

MDN Web Docs 由 Mozilla 维护，官方称自 2005 年起持续记录 CSS、HTML 和 JavaScript，是 Web 开发者广泛认可的权威文档来源。除核心技术文档外，还覆盖 Web API、浏览器兼容性、安全与最佳实践等主题，并提供精选文章与更新博客。中文站点提供高质量的简体中文页面，适合作为日常查阅与系统学习的基线资料。

适用场景

  • 查某个 HTML 标签、CSS 属性或 JS 方法的准确用法
  • 学习 Web API 的兼容性与使用示例
  • 系统梳理前端知识体系

核心功能

  • 覆盖 HTML / CSS / JavaScript 与 Web API
  • 提供简体中文页面
  • 内容持续更新，与规范同步
  • 示例代码与兼容性说明
  • 免费开放，无需注册

✓ 有依据的优点

  • 权威性与准确度高，被广泛引用
  • 中文翻译质量在技术文档中属上乘
  • 免费、无广告、无需登录

✕ 有依据的缺点

  • 偏查阅型，不适合零基础从头学
  • 中文页面覆盖不如英文完整
  • 只覆盖 Web 技术栈

使用限制

  • 以文档为主，不提供视频教程与体系化课程
  • 部分较新或较少用的 API 中文翻译滞后
  • 不涉及后端与运维等非 Web 领域

推荐理由

当你不确定某个前端 API 的准确行为或兼容性时，直接查 MDN 最可靠；入门阶段可配合教程类站点一起使用。
